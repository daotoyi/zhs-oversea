### 1.2 银行开户（真实耗时最长的一环）
- **虚拟银行优先**：ZA Bank、Mox 开户费为零、无最低存款门槛，适合 v1
- **传统银行**：汇丰、渣打免首年管理费，但需存入 HK$10,000–50,000 激活
- 材料：CI、BR、章程、NNC1、董股身份证件（护照/身份证）、住址证明（6 个月内）、业务计划书
- 周期：**3–7 个工作日审核**，多数需董事面签，部分中小银行要求本人赴港
- ⚠️ 关键：银行开户用途说明必须与业务实际一致（道家文化/文创产品跨境电商），且能说清供应链与发货地（北京）

### 1.3 香港公司的税务要点
- 利得税：标准 16.5%，**首 200 万利润减半至 8.25%**
- 无外汇管制，可开多币种账户
- 每年须由持牌会计师出具审计报告并报税

## 二、支付架构（决策 1 + 3 联动）

### 2.1 双通道总览

```
实物文创 ──→ Stripe 香港主体（香港账户结算 USD）
              3.4% + US$0.30，跨境卡 +0.5%
              └→ Airwallex / 万里汇 ──→ 境内人民币

数字产品 ──→ Stripe Managed Payments（MoR）
              3.5% + 标准处理费，美国卡实收约 6.4% + $0.30
              └→ Stripe 直接结算到香港账户，Stripe 承担税务申报/争议/欺诈
```

### 2.2 实物：Stripe 香港主体（不变）
- 费率：美元结算 3.4% + US$0.30；跨境卡另加 0.5%；货币转换 1%
- 综合到手成本（含结汇）：**约 4.6%–5.5%**，须计入定价
- 美国站关键：**Stripe Tax** 自动计算 50 州销售税 + 经济关联监控 + 帮你注册。门槛 $100k 或 200 单（加州/德州/纽约/阿拉巴马/密西西比为 $500k 销售额；缅因、新墨西哥等 17 州仅 $100k 无笔数门槛；4 州无销售税）
- 拒付防守：Stripe Radar + 3DS 3.0 + 可追踪物流，首月拒付率守 <1.2%

### 2.3 数字：MoR 选型修正 —— 改用 Stripe Managed Payments（重要）

**原 v1 方案写的是 Paddle / Lemon Squeezy，2026 年 10 月的实际情况已变：**

| | Stripe Managed Payments | Paddle | Lemon Squeezy |
|---|---|---|---|
| 费率 | 3.5% + 标准处理费（美国卡 ≈ 6.4% + $0.30） | 5% + $0.50 | 5% + $0.50 + 国际卡 1.5% + 订阅 0.5% |
| 香港主体可用 | ✅ 明确在支持名单内 | ⚠️ 需申请审核 | ❌ 大陆主体新申请受限 |
| 实物商品 | ❌ 仅数字产品 | ❌ 仅数字产品 | ❌ 仅数字产品 |
| 独立结账页 | ⚠️ 仅 Stripe Checkout / Payment Links，账单显示 LINK.COM | ✅ 完全自有品牌结账 | ✅ |
| 税务覆盖 | 80+ 国家间接税 | 30+ 国家 | 30+ 国家 |
| 附加能力 | 复用已开通的 Stripe 账户，一次搞定实物 + 数字 | 独立账户，与实物通道割裂 | 2026-01 官方宣布转向 Stripe MP，支持与更新放缓 |

**结论：数字产品改走 Stripe Managed Payments。**
理由：
1. 香港主体在官方支持名单内，无需二次主体审核
2. **一个 Stripe 账户同时承载实物 + 数字**，Webhook、结账、报表、对账全部统一
3. 费率与 Paddle 差距约 0.7 个百分点，但省掉一整套独立接入、税务谈判与财务对账成本
4. Lemon Squeezy 明确不建议新项目入坑（已被 Stripe 收购、2026 起停止接受大陆主体新申请）

**唯一代价**：Managed Payments 走 Stripe 托管结账页，账单上显示 LINK.COM 而非品牌名 —— 对数字产品（会员/课程）影响可接受，且可在上线后视情况再评估。

**MoR 边界（务必记住）**：
- Managed Payments **不支持实物商品**，实物必须留在标准 Stripe
- 买家侧排除中国、俄罗斯、伊朗、朝鲜、叙利亚、古巴等受限地区
- 与 Stripe Connect / Express 账户互斥

## 四、合规与选品（决策 4 + 5）

### 4.1 朱砂保留的具体做法（决策 4）
**结论：保留，但必须改造工艺与文案，且美国站先行、欧盟站延后。**

| 项 | 要求 |
|---|---|
| 工艺 | **封闭式封装**（金箔/银笼/隔层玻璃），杜绝皮肤直接接触 |
| 检测 | ISO 17025 实验室重金属溶出报告（汞/铅/镉），报告编号公示于商品页 |
| 标签 | 明确标注 "Display piece — not for direct skin contact" |
| 文案 | 禁用一切功效词（治愈/净化/转运/招财/改命）。改写为材质与工艺叙事 + "traditionally regarded as..." 的文化归属表述 |
| 美国额外 | 加州 Prop 65 警示语；CPSC 儿童可接触商品禁含朱砂 |
| 欧盟（第三阶段） | REACH 首饰汞零容忍 —— **必须先有替代方案**（南红、鸡血玉、龙血树脂），或坚持封闭式 + 逐批送检 |
| 定价逻辑 | 封装的工艺溢价正当，且有检测报告背书 —— **这是 $45 卖到 $119 的合法理由** |

### 4.2 CITES 物种（决策 5：可拿）
既然证明可拿，按流程建制度：

| 物种 | CITES 状态 | 必持文件 |
|---|---|---|
| 沉香（Aquilaria 属全部） | 附录 II | 中国出口 CITES 证书 + 种植地证明 + 美方进口许可（USFWS） |
| 檀香（Santalum album） | 附录 II | 同上 |
| 小叶紫檀（印度黄檀） | 附录 II | 同上 |
| 雷击原木 / 枣木 / 桃木 / 普通硬木 | 非管制 | 树种与产地声明即可 |
| 砗磲 / 玳瑁 / 象牙 / 犀角 | 附录 I 或全面禁止 | **不上架** |

**落地流程**：
1. 建「CITES 证书台账」—— 每批次记录：物种、学名、来源、出口证书编号、有效期、对应 SKU
2. 商品页强制字段：`citesStatus`（regulated / not-regulated）+ `citesPermitNo`（可查）
3. 无证的**一律不上架**，不靠"个人自用少量豁免"（该豁免在跨境电商场景不成立）
4. 打样阶段就让供应商把证书一起发来，不要等到出货才问
